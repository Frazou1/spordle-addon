# Spordle Hockey Stats

**Français** — Lit les pages publiques d'une équipe de hockey (ligue LHQCA) sur Spordle et publie dans Home Assistant, par MQTT, l'alignement, l'horaire, le dernier match, le classement et les statistiques des joueurs. Les mises à jour s'accélèrent automatiquement les jours de match. Voir l'onglet **Documentation** ou le [README du dépôt](https://github.com/Frazou1/spordle-addon#français).

**English** — Reads a hockey team's public pages (LHQCA league) on Spordle and publishes the roster, schedule, last game, standings and player statistics to Home Assistant over MQTT. Updates speed up automatically on game days. See the **Documentation** tab or the [repository README](https://github.com/Frazou1/spordle-addon#english).
